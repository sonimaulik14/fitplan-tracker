# Kris Gethin images

The app uses the images in this folder for the hero banner, day cards, plan
thumbnails and the landing page. Right now each one is a branded placeholder
(`.svg`). To use **real Kris Gethin photos**, just drop a `.jpg` (or `.png`)
with the matching name into this folder — the app prefers the photo and falls
back to the placeholder automatically. No code change needed.

Add any of these files (only the ones you have are needed):

| File you add        | Used for                          |
| ------------------- | --------------------------------- |
| `hero.jpg`          | Landing + dashboard hero banner   |
| `legs.jpg`          | Legs day                          |
| `chest.jpg`         | Chest day                         |
| `back.jpg`          | Back day                          |
| `shoulders.jpg`     | Shoulders day                     |
| `arms.jpg`          | Biceps / Triceps day              |
| `abs.jpg`           | Abs / core day                    |
| `calves.jpg`        | Calves                            |
| `cardio.jpg`        | Cardio day                        |
| `rest.jpg`          | Active rest / recovery day        |

Tip: landscape images around 1200×800 look best for the hero; the day cards
crop to fit. These are for your personal training tracker.
